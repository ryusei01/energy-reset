# 開発ロードマップ

## MVP（今回）
- Expo Routerによるホーム・ゲーム・タスク・分析画面
- SQLiteによる体調・ゲームセッション・タスク・XP保存
- 4種類のミニゲームの初期実装
- ゲーム前後の自己評価

## 次の段階
1. 呼吸ガイドをアニメーション化し、音声・振動のON/OFFを追加
2. リズムゲームに音源と判定タイミングを実装
3. バブルゲームの難易度と演出を改善
4. クエストとタスクを統合し、キャラクター育成を追加
5. 睡眠記録画面、通知、分析グラフを追加
6. 実機テスト、アクセシビリティ、バックアップ機能
7. 研究文献を明示した説明と効果検証プロトコル

## 設計上の注意
ゲームのスコアは健康改善の指標としない。自己評価の変化には自然変動や期待効果が含まれるため、治療効果とは区別する。
